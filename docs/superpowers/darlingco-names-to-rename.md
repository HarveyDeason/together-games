# Darling & Co. — every name, for renaming

Everything below is a placeholder. Reply with new text for any number; leave out anything you are happy with.
All of it lives in one file (src/games/darlingco-board.js), so renaming is a data edit, not a code change.

**A note on length:** tile names render at about 5px on a phone, in roughly 29x37px tiles, and longer ones
clip to an ellipsis. Short names will look much better. The full name always shows on the property card.
